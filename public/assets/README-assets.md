# Assets Directory Guide

### Profile Photo:
- Place your photo here as: `profile.jpg` (or `profile.png` / `profile.webp`)
- Path: `public/assets/profile.jpg`
- The website automatically checks for this file. If present, it will seamlessly render your photo with an editorial border and frame.
- If not present, it gracefully displays the architectural portfolio emblem.

### Resume File:
- Place your PDF resume here as: `resume.pdf`
- Path: `public/assets/resume.pdf`
- The "Download Resume" buttons in the Recruiter Snapshot modal and Quick Actions will immediately download this file.
